## Artefacto máquina — W3C Design Tokens

Se guarda como `<ID>.json`. **Formato del W3C Design Tokens Community
Group**: `$value`, `$type`, `$description`, y los metadatos de
intención bajo `$extensions`, que es el mecanismo que la propia
especificación define para datos propios — no inventar claves de
primer nivel.

La identidad del contrato (`id`, `version`, `estado`) va en
`$extensions` del **grupo raíz** — no como claves de primer nivel, que
invalidarían el archivo. `/contract-verify` la exige ahí: sin ella el
artefacto máquina no puede llegar a `AGREED`.

```json
{
  "$description": "Fundamentos de <producto>.",
  "$extensions": {
    "ai-dlc": {
      "id": "DS-NNN",
      "version": "1.0.0",
      "estado": "DRAFT",
      "tipo": "design",
      "subtipo": "fundamentos",
      "derived": false,
      "escalas": [{ "id": "S1", "familia": "espaciado", "regla": "" }],
      "temas":   [{ "id": "T1", "tema": "", "cambia": [], "permanece": [] }],
      "accesibilidad": [
        { "id": "X1", "requisito": "", "verificacion": "" }
      ],
      "criterios_aceptacion": [
        { "id": "AC-1", "criterio": "", "verificacion": "", "nivel": "automatico" }
      ]
    }
  },
  "color": {
    "blue": {
      "600": { "$value": "#0B5FFF", "$type": "color" }
    },
    "action": {
      "primary": {
        "$value": "{color.blue.600}",
        "$type": "color",
        "$description": "Acción principal de una vista",
        "$extensions": {
          "ai-dlc": {
            "intent": "Señalar la única acción que continúa el flujo",
            "useFor": ["botón primario", "enlace de acción principal"],
            "avoidFor": ["acciones destructivas", "más de una por vista"]
          }
        }
      }
    }
  },
  "space": {
    "compact": {
      "$value": "8px",
      "$type": "dimension",
      "$extensions": {
        "ai-dlc": {
          "intent": "Densidad alta en tablas y listas largas",
          "useFor": ["filas de tabla", "listas densas"],
          "avoidFor": ["formularios", "contenido de lectura"]
        }
      }
    }
  }
}
```

> `{color.blue.600}` es la sintaxis de alias del W3C: el token
> semántico apunta al primitivo. Cambiar el primitivo cambia el tema
> sin tocar ningún `DC-*`.
